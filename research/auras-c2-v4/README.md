Estos scripts conservan el proceso de investigación y grabación del espacio de trabajo original; usan rutas `work/` y las herramientas locales allí instaladas. La construcción portátil del prototipo utiliza el IPS con `pnpm build:auras:v4 --rom ruta/a/original.bin`. La fuente de ensamblador contiene una tabla reservada que prepare/build rellenan; aura.hex guarda los bytes finales.
