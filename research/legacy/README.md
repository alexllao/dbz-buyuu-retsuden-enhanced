# Fuentes de investigación anteriores al repositorio

Estos archivos conservan los scripts usados para extraer paletas y realizar las comprobaciones históricas. Su estructura `work/` y referencias a `outputs/` pertenecen al espacio de trabajo original.

Son una referencia de implementación, **no la interfaz de construcción soportada**. Para generar las ROMs verificadas usa `pnpm build`; para ensamblar la fuente vigente, `pnpm assemble`. El siguiente trabajo de infraestructura es extraer un replay de QA portable con el núcleo de emulación facilitado por el usuario.

No se incluyen ROMs, bibliotecas del emulador ni instalaciones de Ghidra. La evidencia resumida y la matriz histórica están en `evidence/gameplay-v1/` desde la raíz del proyecto.
